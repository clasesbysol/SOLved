# Publicación en GitHub Pages

## Repositorio recomendado

`biblioteca-lbt`

La dirección pública resultante será:

`https://clasesbysol.github.io/biblioteca-lbt/`

## Pasos

1. Crear un repositorio público vacío llamado `biblioteca-lbt` en la cuenta `clasesbysol`.
2. Marcar **Add a README file** para que el repositorio nazca con la rama `main`. No agregar licencia ni `.gitignore`.
3. Volver al chat: desde ahí se puede subir el proyecto completo en un único cambio organizado.
4. Abrir **Settings → Pages**.
5. En **Build and deployment → Source**, elegir **GitHub Actions**.
6. Abrir **Actions** y esperar que termine `Publicar Biblioteca LBT`.
7. Abrir la URL indicada en el deployment.

Cada cambio posterior enviado a `main` ejecutará pruebas, construirá el sitio y lo publicará automáticamente.
