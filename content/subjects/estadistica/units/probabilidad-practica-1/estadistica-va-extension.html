9. Variable aleatoria discreta: qué estamos describiendo

Una variable aleatoria asigna un número a cada resultado posible de un experimento. La idea importante es que dejamos de mirar el resultado completo y nos quedamos con la característica numérica que nos interesa.

Ejemplo: dos dados.

El resultado completo puede ser (2,5), pero si definimos X = suma de los dados, entonces a ese resultado le corresponde X=7. Muchos resultados distintos pueden dar el mismo valor de X.

Rango de X

El rango RX es el conjunto de valores que realmente puede tomar la variable. Si X cuenta cuántas bolillas blancas salen en dos extracciones, entonces RX={0,1,2}.

Función de probabilidad puntual

Para una variable discreta sí tiene sentido preguntar la probabilidad de un valor exacto.

pX(k) = P(X = k)

La función debe cumplir dos cosas: ninguna probabilidad puede ser negativa y la suma de todas las probabilidades posibles debe dar 1.

pX(k) ≥ 0    y    Σ pX(k) = 1

Función de distribución acumulada

La acumulada responde: “¿qué probabilidad hay de que X sea menor o igual que este valor?”.

FX(t) = P(X ≤ t)

En una variable discreta FX se construye sumando las probabilidades puntuales hasta t. Por eso tiene forma de escalones (cada valor posible agrega un salto).

Mapa mental: experimento → definís X → buscás RX → calculás pX → acumulando pX construís FX.

11. Variable aleatoria binomial

Usamos una binomial cuando hay n ensayos de Bernoulli (cada ensayo sólo tiene éxito o fracaso), n es fijo, los ensayos son independientes y la probabilidad de éxito p se mantiene constante.

Si X cuenta la cantidad de éxitos:

X ∼ Bi(n,p)
P(X=k) = (nk) pk(1−p)n−k
¿De dónde sale cada parte?
pk representa los k éxitos; (1−p)n−k los fracasos; el número combinatorio cuenta de cuántas maneras pueden ubicarse esos k éxitos entre los n lugares.

El rango es RX={0,1,2,…,n}. Si n=1, la variable se llama Bernoulli.

Ejemplo del apunte.

Si 37% de los estudiantes fuma y se eligen 7 estudiantes con reposición, X=cantidad que fuma es Bi(7,0,37). “Por lo menos 3” se traduce X≥3 y conviene usar complemento: 1−P(X≤2).

Comandos en R del apunte

pX(k): dbinom(k,n,p)
FX(t): pbinom(t,n,p)
12. Variable aleatoria geométrica

Se repite el mismo ensayo, de manera independiente, con probabilidad de éxito p constante, hasta que aparece el primer éxito. X cuenta el número de intento en el que aparece.

X ∼ G(p)
P(X=k) = (1−p)k−1 p    k=1,2,3,…
Razonamiento: para que el primer éxito aparezca en el intento k, necesariamente los primeros k−1 intentos tienen que ser fracasos y el intento k tiene que ser éxito.
Ruleta del apunte.

Hay 2 sectores verdes entre 38. Si éxito=caer en verde, p=2/38. Que hagan falta 3 jugadas significa fracaso, fracaso, éxito.

P(X=3) = (1−2/38)2·(2/38)

Comandos en R

pX(k): dgeom(k−1,p)
FX(t): pgeom(t−1,p)
R usa la cantidad de fracasos antes del primer éxito; por eso en el comando aparece k−1, mientras que el apunte define X como número total de intentos.
13. Variable aleatoria hipergeométrica

Se usa cuando tenemos una población finita de N elementos, D pertenecen a la categoría que llamamos “éxito” y elegimos n elementos sin reposición. X cuenta cuántos éxitos aparecen en la muestra.

X ∼ H(D, N−D, n)
P(X=k) = (Dk) · (N−Dn−k)(Nn)
Lectura de la fórmula: arriba contamos formas de elegir k éxitos y n−k no-éxitos; abajo contamos todas las formas de elegir n elementos de la población.

Los valores posibles de k tienen que ser físicamente realizables:

max{n−(N−D),0} ≤ k ≤ min{D,n}
Urna del apunte.

2 blancas y 7 negras; se extraen 3 sin reposición. Si X=número de blancas, es hipergeométrica. La palabra decisiva es sin reposición.

Comandos en R

pX(k): dhyper(k,D,N−D,n)
FX(t): phyper(t,D,N−D,n)
Binomial vs hipergeométrica: con reposición (o ensayos realmente independientes) la probabilidad de éxito se mantiene; sin reposición cambia después de cada extracción.
14. Variable aleatoria Poisson

Poisson modela un conteo de ocurrencias. El parámetro λ representa el número medio de eventos esperado en la unidad de observación elegida.

X ∼ P(λ)
P(X=k) = e−λ λkk!    k=0,1,2,…
Microorganismos del apunte.

Si el número de microorganismos por gramo sigue Poisson con λ=8, X cuenta microorganismos en un gramo. “La preparación se vuelve turbia” significa X≥1. Si después preguntan por la cantidad sabiendo que se volvió turbia, aparece además una probabilidad condicional.

Comandos en R

pX(k): dpois(k,λ)
FX(t): ppois(t,λ)
No confundas λ con una probabilidad: λ puede ser mayor que 1. Es una cantidad media de eventos, no un número obligado a estar entre 0 y 1.
15. Variable aleatoria continua: qué cambia respecto de una discreta

Una variable es continua cuando entre dos valores posibles hay infinitos valores intermedios. Altura, tiempo, concentración o diámetro son ejemplos típicos.

Como hay infinitos valores posibles, en una muestra real casi nunca se repite exactamente el mismo valor. Por eso ya no usamos una función de probabilidad puntual como en las discretas.

P(X=x)=0

Esto no significa que “x sea imposible”. Significa que la probabilidad se reparte en infinitos puntos y la probabilidad relevante se calcula sobre intervalos.

Del histograma a la densidad

El apunte parte de muchas mediciones, las agrupa en intervalos y construye un histograma. La altura de cada barra se elige para que el área represente frecuencia relativa.

altura del rectángulo = frecuencia relativalongitud del intervalo

Con muchas observaciones, la frecuencia relativa de un intervalo se aproxima a su probabilidad. Una curva suave que aproxima ese histograma motiva la función de densidad.

16. Función de densidad: la probabilidad es un área

Una densidad f para una variable continua no da directamente “la probabilidad en x”. Lo que importa es el área bajo la curva entre dos valores.

P(a < X < b) = ∫ab f(x) dx

Tres propiedades que hay que controlar siempre

  • f(x)≥0. Una densidad no puede ser negativa.
  • El área total vale 1. ∫ f(x)dx sobre toda la recta =1.
  • Probabilidad de un intervalo = área. Se integra la densidad entre los límites.
Clave conceptual: la altura f(x) puede incluso ser mayor que 1. Lo que nunca puede superar 1 es una probabilidad, es decir, un área apropiada bajo la densidad.

Extremos abiertos o cerrados

Para una variable continua, incluir o excluir puntos aislados no cambia la probabilidad, porque P(X=a)=P(X=b)=0.

P(a<X≤b)=P(a≤X≤b)=P(a<X<b)
17. Función de distribución acumulada en variables continuas

La función de distribución acumulada sigue significando exactamente lo mismo: probabilidad de estar a la izquierda de x. La diferencia es que ahora se obtiene integrando la densidad.

FX(x) = P(X≤x) = ∫−∞x fX(t) dt

Propiedades

  • 0≤FX(x)≤1.
  • Es monótona no decreciente (al movernos a la derecha nunca podemos perder probabilidad acumulada).
  • Para una variable continua, FX es continua.
  • Cuando x→−∞, FX(x)→0; cuando x→+∞, FX(x)→1.

Para probabilidades entre dos puntos:

P(a<X≤b) = FX(b) − FX(a)
Interpretación: F(b) contiene toda el área a la izquierda de b. Si le sacamos F(a), queda solamente el área entre a y b.
18. Percentiles y cuantiles

Un percentil cambia la pregunta. En vez de darte un valor x y pedir P(X≤x), te dan una probabilidad acumulada y te piden encontrar el valor que la deja a la izquierda.

El percentil p·100% (o cuantil de orden p) es un valor qp tal que, en una distribución continua:

FX(qp) = p
Percentil 90.

q0,90 es el valor por debajo del cual queda el 90% de la distribución. A la derecha queda el 10%.

La mediana es el percentil 50:

FX(q0,50) = 0,50
Para resolver percentiles: 1) escribí F(x); 2) igualala a p; 3) despejá x; 4) verificá que el resultado esté dentro del soporte de la variable.
19. Distribución uniforme continua

En una uniforme U(a,b), todos los subintervalos de igual longitud dentro de [a,b] tienen la misma probabilidad. La densidad es constante: la curva es un rectángulo.

X ∼ U(a,b)
fX(x) = 1b−a   para a≤x<b;   0 fuera del intervalo

La altura 1/(b−a) hace que el área total del rectángulo sea 1.

Función de distribución

FX(x)=0si x<aFX(x)=(x−a)/(b−a)si a≤x<bFX(x)=1si x≥b
Cola de supermercado del apunte.

Si X∼U(1,9), todo el rango mide 8 minutos. Para P(X<6), el intervalo favorable de 1 a 6 mide 5 minutos.

P(X<6) = 6−19−1 = 58
En una uniforme, cuando el intervalo pedido está completamente dentro de [a,b], podés pensar directamente: probabilidad = longitud favorable / longitud total.
